About & Methodology

Technical details about the camouflaged object segmentation approach, model architecture, datasets, and training.

Problem: Camouflaged Object Segmentation

Camouflaged object segmentation (COS) aims to identify objects that blend seamlessly into their surroundings. Unlike traditional salient object detection where objects stand out, camouflaged objects share similar texture, color, and intensity patterns with the background, making them extremely challenging to detect.

Standard Segmentation

Clear boundary between object and background

Camouflaged Segmentation

Object mimics background texture, color, and intensity

Model Architecture: U-Net with ResNet34 Encoder

Architecture Details

  • Encoder: ResNet34 pre-trained on ImageNet
  • Decoder: U-Net upsampling with skip connections
  • Output: Single-channel binary mask (logits)
  • Activation: Sigmoid applied at inference (threshold 0.5)
  • Loss: BCE + Dice Loss combination
  • Optimizer: Adam (lr=1e-4 for RGB, 1e-5 for others)

Depth Estimation: Depth Anything V2

Why Depth Helps

Camouflage works by matching appearance (color/texture) but rarely matches 3D geometry. Depth provides geometric cues that break the camouflage illusion.

  • • Monocular depth estimation — no stereo required
  • • Pre-trained on massive diverse dataset (62M+ images)
  • • Robust generalization to unseen scenes
  • • Normalized to [0, 1] per image for consistent input
  • • Cached as .npy files for training efficiency

Integration Pipeline

  1. Input RGB image (352×352)
  2. Depth Anything V2 → depth map (H×W)
  3. Normalize depth to [0, 1] per image
  4. Concatenate as 4th channel: [R, G, B, Depth]
  5. Feed to 4-channel U-Net

⚠ For website uploads: depth must be generated on-the-fly using the same Depth Anything V2 model.

Preprocessing

  • • Resize all images and masks to 352×352
  • • RGB normalization: ImageNet mean/std ([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
  • • Masks: nearest-neighbor resize → binary 0/1
  • • Depth maps: per-image min-max normalization to [0, 1]
  • • Canny edges: cv2.Canny(gray, 100, 200) → normalized to [0, 1]

Evaluation Metrics

Dice Coefficient (F1)

Measures overlap between prediction and ground truth. Range: 0–1 (higher is better). 

Dice = 2 × |P ∩ G| / (|P| + |G|)

Mean Dice: Average per-image Dice
Global Dice: Aggregate pixels across dataset first

Intersection over Union (IoU)

Jaccard index — overlap over union. Range: 0–1 (higher is better). 

IoU = |P ∩ G| / |P ∪ G|

Mean IoU: Average per-image IoU
Global IoU: Aggregate pixels across dataset first

Threshold: Model outputs logits → sigmoid → threshold at 0.5 for binary mask

Limitations & Future Work

Current Limitations

  • • Fixed 352×352 input resolution
  • • No test-time augmentation
  • • Single threshold (0.5) for all datasets
  • • Depth generated offline for training (not end-to-end)
  • • Canny thresholds fixed (100, 200) — not learned
  • • Combined model doesn't outperform depth-only

Future Improvements

  • • Multi-scale training & inference
  • • Learnable edge/depth fusion modules
  • • End-to-end depth estimation fine-tuning
  • • Transformer-based decoders (Swin, MiT)
  • • Boundary-aware losses
  • • Video camouflaged object segmentation
